# 知识图谱可视化详细设计

> 所属类别：第 4 类 - 详细设计
> 创建日期：2026-08-15
> 状态：实施中（Phase A 后端）

## 1. 背景与目标

为 MemoMind 增加知识图谱可视化页面，展示笔记关系网，并把已有的分析能力（社区检测、健康报告）可视化出来。

**方案**：③ ECharts 展示 + 后端算分析（对标 Obsidian 图谱 + Advanced Graph 插件部分能力）。

## 2. 设计决策

| 决策点 | 结论 |
|--------|------|
| 前端技术 | ECharts（graph force 布局）+ `echarts-for-react` |
| 分析位置 | 后端算好，前端只着色展示 |
| 数据源 | `build_graph()`（nodes/edges）+ `detect_communities()`（社区）+ `lint_knowledge()`（健康状态） |
| API | 新增 `GET /api/graph`（保留旧 `/api/links/graph`） |

### 返回结构

```python
{
  'nodes': [
    {
      'id': 1,
      'label': '笔记标题',
      'tags': [...],
      'importance': 0.5,
      'group': '编程',              # build_graph 的 _assign_group
```

## 4. API 端点

`GET /api/graph?workspace_id=&max_nodes=` → 返回 `get_graph_with_analysis()` 结果。

## 5. 前端（Phase B，本文档仅记录设计）

- 节点颜色 = `community`；孤儿 = 灰色虚线；该删候选 = 红色
- 节点大小 = `importance`
- 边颜色按 `type`（link/tag/similarity）
- 点击节点 → 跳转 `/notes/:id`
- 过滤：边类型、`max_nodes`

## 6. 测试策略（Phase A）

| 测试 | 验证 |
|------|------|
| 返回结构 | nodes 带 community/is_orphan/is_delete_candidate 字段 |
| 空库 | 返回空 nodes/edges |
| 孤儿标注 | 孤立节点 is_orphan=True |

测试命令：`python -m pytest tests/test_knowledge_graph.py -v --tb=short`

```
Phase A：后端 get_graph_with_analysis + 测试 + /api/graph   （本文档）
```

## 8. 风险

- `echarts-for-react` 对 React 19 兼容性待验证（不行则原生 echarts + 自定义组件）
- ECharts force 大图性能，默认 `max_nodes=100`
