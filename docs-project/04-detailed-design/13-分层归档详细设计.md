# 分层归档与智能触发详细设计

> 所属类别：第 4 类 - 详细设计
> 创建日期：2026-08-15
> 状态：实施中

## 1. 背景与目标

当前 `is_archived` 只在 Dreaming 选择时生效（排除重复处理），但归档笔记在搜索/列表/图谱中**仍然可见**，处于「半隐藏」状态。本设计将归档演进为「分层归档」：默认隐藏 + 可追溯。

**核心原则**（借鉴 OpenClaw self-improving）：**只降级不删除**——归档笔记保留在库中，默认不出现，但可显式追溯。

## 2. 设计决策（经六顶思考帽审视）

| # | 决策 | 结论 |
|---|------|------|
| 1 | 搜索处理 | **降权显示**（排末尾 + 灰色 + 已归档标签），不做排除开关 |
| 2 | 追溯入口 | **通过合并笔记反查**（supersedes 边）+ 列表页「归档 N 条」兜底入口 |
| 3 | 数据模型 | 加 `archived_at` 字段（旧数据回填用 `updated_at`） |
| 4 | 列表/图谱 | 默认排除归档（活跃视图） |

## 3. 数据模型

`notes` 表加 `archived_at TIMESTAMP`（可空，归档时写入）：

```sql
ALTER TABLE notes ADD COLUMN archived_at TIMESTAMP;
```

旧归档笔记回填：`archived_at = updated_at`（近似值）。

## 4. 各视图行为

| 视图 | 归档笔记处理 |
|------|-------------|
| 搜索 | 降权：`ORDER BY is_archived ASC, score DESC`，结果带 `is_archived` 标记 |
| 列表 | 默认排除：`AND is_archived=0` |
| 图谱 | 默认排除（build_graph 加 is_archived=0 过滤） |
| Dreaming | 排除（已实现） |
| 归档入口 | `GET /api/notes/archived` 返回归档列表（按 archived_at 倒序） |
| 碎片反查 | note 详情返回 `merged_sources`（supersedes 反查） |

## 5. 实现要点

### 5.1 `SearchService.search()`

SELECT 末尾加 `n.is_archived`（避免打乱 `Note.from_row` 列顺序）：

```sql
SELECT n.id, n.title, n.content, n.tags, n.created_at, n.updated_at,
       bm25(notes_fts) as score, n.is_archived
FROM notes_fts JOIN notes n ON notes_fts.rowid = n.id
WHERE notes_fts MATCH ? {tag_filter}
ORDER BY n.is_archived ASC, score DESC
LIMIT ? OFFSET ?
```

`SearchResult` 加 `is_archived: bool = False` 字段。

### 5.2 列表排除归档

`GET /api/notes` 的 SQL 加 `AND is_archived=0`。

### 5.3 归档入口

新增 `GET /api/notes/archived`：返回 `is_archived=1` 的笔记列表（含 title/archived_at/type）。

### 5.4 碎片反查

`GET /api/notes/{note_id}` 返回增加 `merged_sources`：查 `note_links` 里 `source_note_id=note_id AND link_type='supersedes'` 的 target，返回碎片 id/title/archived_at。

### 5.5 归档写入

`DreamingService.merge_cluster` 归档时：`UPDATE notes SET is_archived=1, archived_at=? WHERE id=?`。

## 6. 智能触发（A）

### 6.1 现状与目标

`DreamingScheduler` 固定凌晨 3 点跑，不看库里有几条、有没有新增。目标：每次 tick 先判断「该不该整理」，达标才跑。

### 6.2 设计

`DreamingScheduler` 加 `should_dreaming()`：

```python
def should_dreaming(self) -> bool:
    # 1. 记忆数阈值（活跃笔记 >= min_notes）
    # 2. 距上次 Dreaming >= min_days
```

`_on_tick` 先判断，不达标跳过并调度下一次。

### 6.3 阈值（默认）

| 参数 | 默认 | 说明 |
|------|------|------|
| `min_notes` | 50 | 活跃笔记数下限 |
| `min_days` | 7 | 距上次整理天数下限 |
